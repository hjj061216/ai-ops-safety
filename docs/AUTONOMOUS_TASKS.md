# 登录身份与自主多步骤任务

默认执行环境为本地模拟器；显式指定 `--diagnostics-config` 可启用 [真实本机只读诊断](REAL_DIAGNOSTICS.md)，该模式拒绝全部变更操作。

模型默认由 DeepSeek 官方 API 提供，设置 `DEEPSEEK_API_KEY` 即可；无需运行 Ollama。配置见 [DeepSeek API 指南](DEEPSEEK_API.md)。云端负责理解与规划，本地负责安全控制，以及按所选模式模拟执行或只读采集。

## 首次配置账号

安装依赖后在项目根目录运行，密码由终端隐藏输入：

```powershell
.\.venv\Scripts\python.exe scripts/manage_users.py alice operator
.\.venv\Scripts\python.exe scripts/manage_users.py bob approver
# 需要配置修改权限时，另外建立管理员：
.\.venv\Scripts\python.exe scripts/manage_users.py carol admin
```

Linux 使用 `.venv/bin/python`。用户名与角色保存在本地运行目录，密码以 scrypt 加随机盐保存。会话默认1小时，使用 HttpOnly / SameSite=Strict Cookie 与写接口 CSRF 校验。服务端拒绝请求字段伪造角色、申请人和审批人。账号停用与角色变化在后续请求和每步执行前重新读取。

候选、任务、操作绑定提交用户。操作员可申请重启，管理员可申请配置修改；审批员与管理员可审批，但不能批准自己的请求。回滚单独检查角色与归属；管理员可执行维护恢复。重启后端会使旧会话、候选及内存任务失效，历史操作与归属记录保留。

## 一次启动，多步处理

1. 登录后输入目标，勾选只读自动执行权限，创建任务并审阅初始计划。
2. 点击“启动自主执行”。后台执行规划、范围检查、授权、工具执行、观察和再规划，低风险查询无需逐步点击。
3. 遇到变更或模型判为中高风险的步骤，系统创建绑定候选的申请并暂停。
4. 另一人通过顶栏“新标签页登录其他账号”登录审批账号，在审批队列核对工具、参数、申请人和原因后批准。请新建标签页，避免使用浏览器“复制标签页”。
5. 审批员不会得到申请人的令牌；后台为原任务提交人领取并一次性消费令牌，恢复执行，最后展示执行证据。

可请求停止；正在执行的操作不会被强行中断，但后续步骤会停止。退出登录会取消该用户后续自动步骤。仍可使用逐步手动模式。

示例：`检查 nginx 状态，再查看最近2行错误日志，最后总结`。

条件示例：`先检查 nginx 状态，如果服务异常就重启 nginx，再检查状态`。只有服务器实际记录的状态证明异常时，才能生成条件重启候选，之后仍需独立审批。当前只支持明确的服务异常条件，不支持任意条件语言；模拟服务默认正常，因此通常不会触发条件重启。

## 风险和循环边界

工具及资源的唯一配置入口是 `policy/tools.yml`：声明参数、允许服务/路径、风险、角色、读写类型、已配置错误日志与默认读取行数。`ops_catalog.py` 为解释器、任务规划、安全网关及本地执行器提供这些定义；调整配置后需要重启后端。

`task_scope.py` 将用户原文整理成服务端任务范围：目标服务、日志资源、禁止事项、缺失参数和必要步骤。页面展示默认资源和未完成事项；模型收到同一范围及实际观察。普通查询与诊断范围采用保守规则识别，仍不是任意自然语言的完整语义理解。

关键信息不全时，先通过输入安全检查，再追问服务名、日志路径或配置全文。不支持的请求有单独状态，不伪装成验证器故障。模型每轮只提议下一步，Guardrails AI 检查结构和范围，服务端再检查前置条件、重复调用、必要步骤及参数。输出不合格最多允许模型纠正一次，两次均使用相同安全校验；验证失败不能执行。

追问由服务端确认的缺失参数触发。例如“重启nginx服务”已指定目标，会直接进入规划；“重启服务”才追问名称，补充唯一服务名后继续规划。参数齐全时，生成结构和 Guardrails 范围验证都不接受模型重复追问；先纠正一次，仍不合格则停止，不生成工具调用。补充名称不能把明确指定的其他服务或禁止重启的约束改成授权。

用户明确要求的查询不能在未执行时报告完成。条件重启只依据服务端记录的状态决定是否必要；实际执行重启后必须再次查询状态，之后才允许任务完成。日志和配置正文不能授权额外操作。此完成检查核对步骤与证据，不保证模型总结的每一句话都正确。

只读自主授权不等于变更授权。整任务命中 critical 规则仍拒绝；前置查询按实际动作、工具和模型风险判断，不把后续变更风险套到所有查询上。模型对查询判为 medium/high 时仍需审批，参数命中危险规则也不会放行。观察结果不能授权新变更。

最多执行6步、补充4次、15分钟有效。已完成目标从后续工具中收窄，变更后可重新查询验证；重复动作、未知执行结果、预算耗尽和越权会停止。输入和工具结果按规则检查，不保证检测所有提示注入；模型总结也不等于独立事实核验。

任务候选的有效期不超过任务期限。停止任务或退出登录会作废未执行候选；已结束任务需重新创建，不能复用旧候选从页面手动继续。执行中的操作仍可能完成，停止不能代替回滚。模型连接失败、权限不足及安全验证失败分别解释，技术原因放入详细信息中。

## 验证范围

自动测试覆盖真实 HTTP 登录、伪造身份、候选/任务隔离、令牌领取、自我审批、回滚权限、后台多步执行、审批暂停与自动恢复、停止和条件证据检查。固定规划返回值及受控云端响应验证控制流；真实模型效果需要另用有效的 DeepSeek API 密钥试用。

默认模式使用模拟服务和演示文件；查询磁盘读取实际容量。显式启用真实只读模式后，健康检查和日志读取来自维护者配置的本机资源，但不会执行服务变更。演示测试服务的故障内容是预设样本，不能据此宣称已经验证真实 Nginx 的修复效果。
